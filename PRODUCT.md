# PRODUCT.md - Sistema Escolar

## Propósito
Sistema web administrativo y pedagógico diseñado para optimizar la gestión escolar, registro de asistencias, notas y comunicación institucional.

## Audiencia Objetivo
- Docentes, preceptores, directivos y estudiantes.
- Interfaz clara y ágil para usar en computadoras del colegio y teléfonos móviles.

## Pautas de Diseño e Interfaz (Impeccable Style)
- **Estilo:** Limpio, moderno, profesional, sin recargar la pantalla.
- **Paleta de Colores:** 
  - Primario: Azul institucional (`#1e3a8a` / `#2563eb`).
  - Fondo: Blanco o gris muy claro (`#f8fafc`).
  - Superficies/Tarjetas: Blanco (`#ffffff`) con bordes sutiles.
  - Alertas/Estados: Verde para aprobado/presente, rojo/naranja para ausente/observaciones.
- **Tipografía:** Sans-serif legible e higiénica (`Inter`, `system-ui`).
- **Componentes:** Tarjetas limpias, tablas de datos ordenadas con buen espaciado y botones legibles con alto contraste.
